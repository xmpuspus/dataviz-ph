The explorer shows source limits with each view

The first chart stays static. Select Play the guided story for the explanation. Select Explore the data for direct control.

The 82-area contract keeps historical comparisons stable

The analysis layer has 81 provinces and virtual NCR. The versioned crosswalk keeps source-native identifiers and records each transform.

Highly Urbanized Cities roll up to parent provinces. The crosswalk records historical Maguindanao, the Negros Island Region change, and the Sulu transfer.

Population uses the 2020 and 2024 anchors. The build estimates 2021 through 2023 between the two anchors. Per-capita denominators follow this contract.

The shipped data has defined coverage

GDP covers 2018 through 2025. Poverty-depth data ends in 2023. PSA poverty-depth tables use 1F/FY. The chart marks partial coverage and unavailable indicators.

PhilGEPS figures are contract awards, not disbursements. Awards show committed contract value. They do not show cash paid to a project.

Correlation describes association. It does not prove causation.

The 2025 workbooks need source gates before publication

The official 2025 poverty and FIES workbooks do not ship. They need source, precision, crosswalk, weight, and revision gates before publication.

If a workbook passes, the explorer labels its figures preliminary. The view then states the source date, precision, and revision policy.

PhilGEPS 2025 is unavailable. The reviewed snapshot fails incomplete-date, invalid-date, future-date, and correction-comparison gates.

DBM COMPASS and CBMS are adoption-gated. They need access, grain, coverage, and suppression contracts before the product can use them.

The trust panel gives the evidence for the active view

View evidence, shown as Why trust this view, lists source, update, grain, transforms, status, coverage, warnings, and archive information. The coverage table lists full, partial, and unavailable years.

Each view can download CSV data, metadata JSON, and citation text. The metadata JSON includes the view URL, method URL, source and build identifiers, warnings, and coverage.

Curated views and stateful links preserve the active view. Embed attribution links back to the full explorer with the same state.

The build refreshes PSA data but not protected sources

`--no-cache` refreshes PSA data. The build reads the committed geography contract.

The build does not get PhilGEPS snapshots or protected 2025 workbooks. A maintainer must review and commit a source artifact before a build can use it.

The source ledger states what the product ships

Read the dated source status ledger in `docs/roadmap.md` for shipped, unavailable, and adoption-gated sources.
